# 🚀 Cosmic Survivor

Roguelike Survivor game for Yandex Games platform.

## Features
- 🎮 Auto-attacking roguelike survivor gameplay
- 🚀 4 unique ships with different abilities
- 🔫 6 weapon types (Blaster, Shotgun, Laser, Orbital, Missiles, Lightning)
- 👾 6 enemy types including bosses
- 💎 Power-ups and XP system
- 🏪 Persistent shop with upgrades
- 📱 Mobile support with virtual joystick
- 🎵 Procedural audio effects
- ✨ Particle system with glow effects
- 🌌 Parallax starfield background
- 🏆 Yandex Games SDK integration (leaderboards, ads, cloud saves)
